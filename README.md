Reliable Command-Line Utility

Expense Tracker

A beginner-friendly C++ command-line expense tracker that allows users to add expenses, view expenses, calculate category totals, and calculate the overall expense.

Features

- Add a new expense
- List all expenses
- Calculate total for a category
- Calculate overall expense
- Validate invalid input
- Prevent the program from crashing on unexpected input
- Simple menu-driven interface

Technologies Used

- C++
- Standard C++ Library
- Command-Line Interface

How to Run

1. Download or clone this repository.
2. Compile the program using a C++ compiler.
3. Run the generated executable.

Example:

g++ main.cpp -o expense_tracker
./expense_tracker

Menu

1. Add Expense
2. List Expenses
3. Category Total
4. Overall Total
5. Exit
